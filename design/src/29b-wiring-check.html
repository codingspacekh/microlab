29b · The check before running (M9 design) — pressing Run first looks over the circuit and the code for what is easy to miss (F-18): a part's leg in a column nothing else is in (the green LED's short leg: not joined to GND); a wire that ends where nothing is (GP11's, in column 24); a pin the code uses with nothing wired to it (GP12, line 6, read from main.py's Pin(12, …)). Each says what to do, and Show rings it on the canvas (or goes to the line). Run anyway runs it as it is — the sim shows what a real board would do (here the green LED stays dark); Cancel goes back to fix it. With nothing found it just runs. The same list is in Problems until it is fixed. A setting turns the check off
