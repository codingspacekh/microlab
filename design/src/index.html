Static screens for review before coding. Each screen fills the browser window like the app's own window (1440 × 900 in a 1520 × 1010 window); resize it to see the layout follow — nothing has one fixed width (N-13). Requirement IDs (F-12, Q4…) refer to docs/01-analysis-and-requirements.md. The boards, breadboard and parts are drawn from their real pin positions, so every wire ends on a real pin or hole, and the numbers shown (5.9 mA, 34.0 cm) are worked out, not made up.

Rebuild

  1. Edit design/src/*.html, the drawings in design/svgparts.py or the circuits in design/scenes.py.
  2. Run python3 design/build.py — it writes design/screens/.

Import into Figma (optional)

  1. Install the html.to.design plugin in Figma.
  2. Open a screen in the browser, or point the plugin at the file, and import it as a frame — make the browser window 1520 × 1010 first to get a 1440 × 900 frame.
