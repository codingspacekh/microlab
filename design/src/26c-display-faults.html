26c · A digit needs its resistor (M7 design, slice 2; milestone tests) — a 7-segment digit with its COM straight on GND: each segment is an LED, so with no resistor the first one lit (a, on GP18) draws far more than a pin can give — the pin is damaged and the run stops, as screen 04's LED; the card says why, with the numbers, and the fix — a 220 Ω on COM, or one on each segment. A 16×2 LCD on 3V3 is a warning, not a stop: the code runs, but its letters are too faint to read (an LCD needs 5 V). Both are in Problems (F-24)
