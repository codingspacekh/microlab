## The rule
**Current = push ÷ holding back.** Scientists write it **I = V ÷ R** and call it **[Ohm's law]**. 3 V ÷ 150 Ω = 0.02 A, which is 20 mA.

## The three words
| Voltage | the push | how hard the battery pushes; in [volts = volt] (V) |
| Current | the flow | how much goes past each second; in [amps = amp] (A) or [milliamps = milliamp] (mA) |
| Resistance | the holding back | how narrow the path is; in [ohms = ohm] (Ω) |
