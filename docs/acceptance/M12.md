## The feasibility spikes (2026-11-09)

| Runtime | What was tried | Result |
|---|---|---|
| **Pyodide** 314.0.7 (CPython 3.14 as WebAssembly, MPL-2.0; ~13 MB) | In Node: load, print, a class, an error, `input()` (a synchronous stdin), Stop (an interrupt buffer set from another thread), `time.sleep(0.5)`, imports, a library from PyPI (micropip) | Loads in 2.2 s; Python 3.14.2; CPython's own messages; `input()` answered; KeyboardInterrupt 36 ms after Stop; sleep 504 ms; `art` installed from PyPI. **No `turtle`, no `tkinter`** (nor IDLE) — rejected (Q22) |
| **CPython 3.13.18**, python-build-standalone 20261026, x86_64-apple-darwin, install_only (25 MB) | Run by the teacher on the development Mac (Intel; the arm64 build fails there: spawn error −86): versions, `input()` through a pipe, Ctrl+C (SIGINT) on a `while True`, an error, `pip install --target` into an app folder and a program using it | Python 3.13.18 with **Tk 9.0.4** (tkinter and turtle import); `input()` answered; KeyboardInterrupt 44 ms after Ctrl+C; CPython's messages; `art` 6.5 installed into the app folder and imported — **chosen** (Q22). First start 3.4 s (cold, unsigned, tkinter and turtle imported): one process is kept ready |
